# Reference projects and candidate components

- [Meet2Notes](https://github.com/estebanstifli/Meet2Notes): meeting capture and analysis reference; review installation and license before reuse.
- [LangGraph](https://github.com/langchain-ai/langgraph): proposed sole orchestration framework.
- [Chroma](https://github.com/chroma-core/chroma): candidate retrieval index; SQLite for task/state persistence.
- [Model Context Protocol](https://modelcontextprotocol.io/): read-only project tools and typed tool contracts.
- [Agent Skills](https://agentskills.io/): instructions and progressive disclosure.
- [Invariant Guardrails](https://github.com/invariantlabs-ai/invariant): candidate runtime security research reference; integration not verified.
- [AgentDojo](https://github.com/ethz-spylab/agentdojo): prompt injection evaluation reference; its official benchmark tasks are not meeting tasks.
- [Langfuse](https://github.com/langfuse/langfuse): candidate trace UI and usage tracking.
- [DeepEval](https://github.com/confident-ai/deepeval): optional quality-evaluation layer.

**Do not claim any of these integrations have been tested until a working proof of concept exists.**
